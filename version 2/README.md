# Portfolio, version 2

The homepage contains one tile for each of the 18 projects. Garment Printing Club, The Limit, Boston Art Review, KURU Fine Dining and Speakerwall Box each cycle through three selected images. The other 13 tiles stay static. Slides pause during hover, keyboard focus, inactive tabs and filtered-out views, and respect reduced-motion preferences.

The scrollbar gutter and filter-marker widths are reserved to keep the header and category buttons aligned when filtering or switching views. Original project content and media remain available on the project pages.

Open index.html, or serve this folder with a local static server. This version is independent of version 1. Do not modify or delete version 1.
