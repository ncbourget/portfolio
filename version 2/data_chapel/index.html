Data Chapel

Electronics • Programming • Installation

Fall 2024

01 Documentation 02 Graphic ephemera 03 Confessions

Data Chapel is an interactive object and program built around a small chapel model that I sculpted from tar, spray foam, and black paint. The software was developed from scratch using Python and Pygame.

Users kneeled before a drawing touchpad and were prompted to make a confession. After drawing whatever they wanted, they could hit send; where it went was left unclear, though each confession was saved to an SD card and later displayed anonymously.

I also created a silkscreen print to supplement the piece, along with a silkscreened shirt containing the collected confessions.
