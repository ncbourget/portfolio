# Search setup

The production address is https://natebourget.com/, taken from the existing CNAME file. This configuration assumes version 2 replaces the website at that address rather than being published inside a version folder.

The homepage, Info and 18 projects have unique search titles, descriptions, canonical URLs, sharing metadata and structured data. The structured data describes Nate Bourget, the portfolio and project work using existing portfolio facts. The sitemap lists these 20 pages. The unfinished personal movie list uses noindex, follow and is excluded from the sitemap.

Each principal page has one first-level heading. Existing project media, descriptions and navigation remain available in HTML. Dimensions are specified for 360 project and profile images to reserve their layout space before loading.

## When publishing

1. Publish the contents of version 2 at the domain root. Preserve version 1 as the local archive.
2. Confirm HTTPS, the preferred hostname and existing project URLs. Redirect alternate hostnames to https://natebourget.com/ using the hosting provider's settings.
3. Verify the domain in Google Search Console using the owner's account. Submit https://natebourget.com/sitemap.xml and inspect the homepage, Info and several projects.
4. Check live titles, canonical URLs and sharing previews after publication. Test structured data and mobile performance against the deployed site.
5. Monitor indexing and queries for Nate Bourget, graphic design, visual identity, editorial design, New York City and Boston. Adjust positioning toward the roles actually being pursued, using accurate experience and project evidence.

Future project additions should receive a unique title and description, an accurate project summary, a representative sharing image and a sitemap entry. Keep movie-list pages out of the professional sitemap while they contain placeholders.
